# App Review 5.1.1(v) 재제출 메모

## 변경 사항

- 앱 첫 화면 상단에 `로그인 없이 합격예측 체험하기` 기본 버튼을 추가했습니다.
- 비회원은 시즌 운영 상태와 무관하게 체험 가능한 시즌으로 바로 이동할 수 있습니다.
- 대학·모집단위 검색, 점수 입력, 예상 내 순위·최초합 순위·예상 추합 순위를 계정 없이 조회할 수 있습니다.
- 비회원의 입력 점수와 예측 결과는 계정 또는 서버에 저장하지 않습니다.
- 로그인은 모의지원 저장·취소와 내 지원내역 관리처럼 계정에 귀속되는 기능에만 필요합니다.

## 심사관 확인 경로

1. 앱을 실행합니다.
2. 첫 화면의 `로그인 없이 합격예측 체험하기`를 누릅니다.
3. 빈 지원 슬롯을 누릅니다.
4. 대학명을 두 글자 이상 입력해 검색하고 모집단위를 선택합니다.
5. 수시는 내신 등급, 정시·모의평가는 환산점수를 입력합니다.
6. `합격예측 보기`를 누르면 로그인 없이 예상 순위 결과가 표시됩니다.

## App Review 회신 초안

안녕하세요.

Guideline 5.1.1(v) 지적에 따라 계정이 필요하지 않은 기능을 회원가입이나 로그인 없이 자유롭게 이용할 수 있도록 첫 화면의 진입 경로를 명확히 수정했습니다.

앱 실행 후 첫 화면 상단의 **“로그인 없이 합격예측 체험하기”** 버튼을 누르면 대학·모집단위 검색, 점수 입력, 예상 내 순위·최초합 순위·예상 추합 순위 조회를 로그인 없이 완료할 수 있습니다. 비회원 체험 데이터는 계정이나 서버에 저장되지 않습니다.

로그인은 모의지원 저장·취소 및 내 지원내역 관리처럼 계정에 귀속되는 기능에만 필요합니다.

확인 경로: 앱 실행 → 로그인 없이 합격예측 체험하기 → 빈 지원 슬롯 → 대학 검색 및 모집단위 선택 → 점수 입력 → 합격예측 보기

감사합니다.
